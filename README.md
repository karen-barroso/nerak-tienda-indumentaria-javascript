# NERAK - Tienda de Indumentaria

NERAK es un proyecto de una tienda de indumentaria femenina que estoy desarrollando como parte del curso de JavaScript de Coderhouse.

A lo largo de las distintas etapas fui incorporando los contenidos aprendidos para mejorar el funcionamiento de la tienda y darle forma a una aplicación web interactiva.

## Arrays

En esta etapa trabajé con arrays y sus métodos para administrar el catálogo de prendas.

- Agregar y eliminar productos.
- Buscar y reemplazar prendas.
- Recorrer el catálogo con `for...of`.
- Validar las opciones ingresadas.
- Simular compras y calcular descuentos.

## Objetos

Incorporé objetos y clases para representar los productos de NERAK.

- Creación de productos con sus propiedades.
- Uso de clases, constructores y métodos.
- Administración de precios y stock.
- Simulación de ventas.

## Funciones de Orden Superior

Incorporé métodos para buscar, filtrar y trabajar con la información del catálogo.

- Búsqueda de productos.
- Filtrado por características.
- Comprobación de condiciones.
- Cálculos y operaciones sobre los productos.

## DOM y Eventos

Incorporé el DOM y los eventos para que la tienda pueda interactuar directamente con el usuario desde la página.

- Visualización dinámica del catálogo.
- Incorporación de nuevas prendas mediante un formulario.
- Eliminación de productos.
- Búsqueda de prendas desde el buscador.
- Actualización del stock al realizar una compra.
- Mensajes en pantalla para informar las acciones realizadas.
- Actualización de la información del catálogo sin recargar la página.

## Asincronismo y Manejo de Errores

Incorporé herramientas para trabajar con operaciones asincrónicas y mejorar la experiencia de uso.

- Uso de promesas y `setTimeout`.
- Implementación de funciones `async` y `await`.
- Manejo de errores mediante `try`, `catch` y `finally`.
- Visualización de mensajes de error y estados de carga en la interfaz.

## Fetch y Librerías

Incorporé la carga de información externa y una librería para mejorar las notificaciones de la tienda.

- Obtención de productos desde un archivo JSON mediante `fetch`.
- Uso de `async` y `await` para gestionar la carga de datos.
- Manejo de errores durante la solicitud.
- Incorporación de Toastify para mostrar notificaciones.

## Proyecto Final - Aplicación Web Interactiva

NERAK evoluciona hacia una tienda online interactiva que permite explorar productos y realizar compras desde la interfaz.

- Catálogo de productos cargado desde un archivo JSON.
- Uso de arrays de objetos y clases para representar las prendas.
- Búsqueda y filtrado de productos.
- Manipulación dinámica del DOM.
- Incorporación de nuevas prendas y eliminación de productos.
- Carrito de compras con posibilidad de agregar, modificar y eliminar productos.
- Cálculo automático de subtotales y total de compra.
- Validación de stock disponible.
- Confirmación de compra y actualización de las cantidades disponibles.
- Persistencia de los datos mediante `localStorage`.
- Notificaciones mediante Toastify.
- Manejo de operaciones asincrónicas y errores.
